# DHA-KT：扩散题目候选的答案条件同化

> 状态：保留研究设计与机制边界；2026-10-19 已完成首版实现与有限流程验收，尚无性能结论。
> 当前代码、可运行命令和实际检查范围见 [dha_kt_usage.md](dha_kt_usage.md)；下文的开发措辞保留设计时语义。
> 配套实施指南：[dha_kt_implementation.md](dha_kt_implementation.md)。

## 1. 研究问题与核心假设

DHA-KT（Diffusion Hypothesis Assimilation for Knowledge Tracing）研究：扩散生成的题目表征候选，能否在已发生的作答证据作用下，形成比固定题目表征更有效的历史交互记忆，并改善学生未来表现预测。

核心链路为：

```text
训练集参考行为证据 → 条件扩散 → 题目候选 Q、Q*1、Q*2、…
                                         ↓
原始历史 → 初步知识状态 → 各候选的作答前预测
                                         ↓ 仅在答案已经观察后
                              答案条件责任权重
                                         ↓
                              历史交互证据编码
                                         ↓
                              后续知识状态与预测
```

核心贡献应集中在“题目候选的答案条件责任分配如何影响未来追踪”。扩散、不确定性、双遍编码、作答后状态更新分别已有先例，不能单独宣称首创。候选均值/分歧不自动等于真实教育语义、真实能力或经过校准的认知不确定性。

需要检验三个假设：

1. 参考行为证据能够支持有用的题目生成候选，候选在预测空间有有效差异。
2. 已观察答案产生的责任权重，优于不读取答案的固定先验权重。
3. 扩散候选优于同预算的确定性映射、Gaussian 候选或 bootstrap 候选。

只有整体 AUC 上升，无法同时证明这三个假设。

## 3. 记号与张量维度

为避免题目语义基底与 batch size 混淆，本文用 S 表示结构基底。

| 符号 | 含义 | 典型维度 |
| --- | --- | --- |
| N、L、K | batch、时间长度、每事件最多概念数 | 标量 |
| d | 原始概念/语义/R 的宽度 | 默认 128 |
| d_q | 最终题目、答案和状态宽度 | d 或 2d |
| S_q | 结构语义，当前为 C_bar + D_q V_bar | d |
| R_q | 题目自由学习的基础残差 | d |
| u_q | 参考行为校准轮廓 | H，建议 8 |
| DeltaR_q^m | 轮廓投影得到的生成修正 | d |
| M | 生成候选数，不含原始 Q | 建议 3 |
| Q_q^0 | 未增强的原始题目 | d_q |
| Q_q^m | 第 m 个完整候选题目 | d_q |
| pi_qm、r_tm | 作答前先验、作答后责任 | M+1 |
| s | 扩散时间步 | 与交互时间 t 区分 |

候选张量为 `[N,L,M+1,d_q]`。所有候选先完成同一种题目融合，再计算均值与方差。

## 4. 题目基底：复用 NewQ V2

当前 NewQ V2 有独立的注意力代码 a_q 与残差代码 z_q：

```text
alpha_qk = softmax_k((gamma/tau) * cosine(a_q, W_K C_k))
C_bar_q  = sum_k alpha_qk C_k
V_bar_q  = sum_k alpha_qk V_k
D_q      = sigmoid(difficulty[q])
S_q      = C_bar_q + D_q V_bar_q
R_q      = W_R z_q
```

仅对当前事件的有效、去重概念计算 alpha；重复概念不能获得额外质量。单概念事件 alpha=1，注意力打分参数没有可辨别的选择作用。R_q 当前是自由学习的低维代码投影，不能将它直接称为真实行为统计。

统一融合函数：

| 配置 | F(S,R) | d_q |
| --- | --- | --- |
| add | S+R | d |
| concat，keep_2d=false | W_f [S;R] | d |
| concat，keep_2d=true | [S;R] | 2d |

W_f 为共享无偏置映射，初始化为 `[I,I]`；原始候选与生成候选必须共用同一 W_f。保留 2d 时，答案嵌入、交互适配器、检索器、预测头全部使用 2d；概念、基础 R、轮廓修正仍为 d。

原始候选定义为 `Q^0=F(S,R)`。如果关闭基础 R，首版限定 add：`Q^0=S`，不创建残差代码表及 W_R。需要保持 2d 容量的“零 R 块”实验应单独命名，不能混同于移除残差模块。

## 5. R 的开关、位置与结合方式

必须区分三个对象：基础 R、生成修正 DeltaR、完整题目 Q。它们不能共用一个含混的“残差”开关。

### 5.1 DHA 正式方案的默认语义

默认使用基础 R；扩散目标为行为轮廓 u，不对 R 或完整 Q 直接加噪；R 默认不作为去噪条件。生成修正进入残差槽：

```text
u_q^m       = ProfileDiffusion.sample(c_q, noise_m)
DeltaR_q^m  = W_u u_q^m              # 无偏置，H→d
R_eff_q^m   = R_q + DeltaR_q^m
Q_q^m      = F(S_q, R_eff_q^m)
Q_q^0      = F(S_q, R_q)
```

因此三种融合下分别为：

| 融合 | 完整生成候选 |
| --- | --- |
| add | S + R + DeltaR |
| concat→d | W_f[S; R+DeltaR] |
| concat→2d | [S; R+DeltaR] |

这种规定把行为修正放入题目特有信息槽，S 不被直接改写。它是设计约束，不保证训练后的 S/R 已实现真实语义解耦。

`W_u` 使用小幅非零初始化；若完全置零，最初 KT 梯度无法穿过它更新生成器。可以通过小幅权重及交互适配器的零初始化控制早期扰动。采样生成的 u 在恢复固定尺度后再投影。

### 5.2 建议保留的 R 对照

| 场景 | 公式/约束 | 研究问题 |
| --- | --- | --- |
| 默认：基础 R＋行为修正 | F(S,R+DeltaR) | 原自由残差与有证据修正能否互补 |
| 去掉基础 R | S+DeltaR，限定 add | 生成行为信息能否替代自由题目残差 |
| 去掉生成修正 | F(S,R)，全部生成候选与原候选一致 | DHA 的退化基线/正确性检查 |
| R 作为条件，detach | 默认公式不变，条件追加 stopgrad(R) | R 的数值能否指导生成，同时限制条件梯度 |
| R 作为条件，可训练 | 默认公式不变，条件追加 R | 条件梯度是否有益；可能更易形成捷径 |
| 语义槽修正，实验项 | F(S+DeltaS,R) | 注入位置是否重要，不能与默认结果混写 |

`learned_residual_enabled=false` 仅关闭基础自由 R，仍可存在生成修正；若要去掉所有残差信息，需要同时关闭生成修正，并令 Q=S。元数据必须明确两者。

R 条件 detach 只切断条件支路；基础 R 经 Q、候选 payload、历史编码与预测的梯度仍存在。固定行为目标另由离线 buffer 与数据构造保证，不能用 R 条件 detach 冒充目标冻结。

### 5.3 与 NewQ V2 四种旧路由的对应

保留 `legacy_question` 候选后端作为对照时，严格沿用旧语义：

| legacy 路由 | 加噪/重建目标 | 独立 R 条件 | 输出后的处理 |
| --- | --- | --- | --- |
| off | S | 无 | Q*=F(S_hat,R) |
| condition | S | R 或 stopgrad(R) | Q*=F(S_hat,R) |
| target | F(S,R) | 无 | Q*=完整生成结果 |
| both | F(S,R) | R 或 stopgrad(R) | Q*=完整生成结果 |

`residual_diffusion_enabled=false` 的旧含义是 off：R 仍融合到 Q 与 Q*，扩散本身也仍运行。target/both 已生成完整 Q，禁止再次加 R、拼 R 或执行 F，否则会重复计入。

正式 `evidence_profile` 后端采用单独的 `profile_residual_condition=none/detach/trainable`，不将行为轮廓目标解释成旧 target/both。此时 legacy_mode=null、legacy_detach=false 是中性值；legacy 后端要求 profile_injection=null、profile_residual_condition=none，并跳过 profile artifact/loss。配置同时激活两种目标体系时应报错；禁止静默忽略。legacy target 生成候选不直接读取当前 R 的性质不意味着 DHA 整体对 R 不敏感，因为原始 Q、查询与历史仍使用 R。

## 6. 行为轮廓：从哪里来，如何避免泄漏

### 6.1 固定坐标定义

参考预测器使用作答前历史得到 p_ref。按固定概率区间（建议 H=8 个等宽区间）分组，最后一区间含 p=1：

```text
u_qb = sum_{i in reference(q,b)} (y_i - p_ref_i) / (n_qb + kappa)
observed_qb = (n_qb > 0)
```

每个坐标表示“该题在参考预测概率层 b 中的校准残差”。不同折使用相同分箱边界；不能以每折自由训练的隐向量为目标后直接当作同一坐标。

首版使用固定缩放（例如 u_scaled=4*u），避免跨折标签拟合出的不同标准化坐标。若使用数据拟合的标准化，必须保存各折参数，并在共享投影前恢复到同一原始轮廓坐标。

首版参考器明确采用低容量 `prefix_beta_skill`，不额外训练神经教师：先以 Beta(1,1) 平滑当前参考学生的全局历史正确率，再以固定强度 5 作为该学生各概念前缀计数的先验，平均当前去重概念的预测概率。先预测、后更新计数，一次多概念作答只更新一次全局计数。空概念用全局前缀概率。该参考器不读当前/未来答案、自由题号嵌入或个人ID特征，不需要拟合校准器；它只是固定概率坐标，不宣称已经校准或等于真实能力。未来替换成可训练参考器时再遵守下面的训练隔离与内部OOF要求。

### 6.2 参考集与交叉拟合

按学生划分训练集内部 F 折。对于训练学生所属折 f，其条件轮廓和目标轮廓只能来自其他折。若使用可训练参考器，该折参考预测器也只能在这些参考学生上训练，不得从已看过 f 标签的全训练集教师热启动后宣称严格排除。

基础 Q 编码器、共享扩散器与 KT 参数仍可通过正常训练监督更新；“排除当前学生”这一声明限定为静态参考特征及去噪目标的构造。不能宣称所有模型参数都没有使用该学生标签。

验证/测试使用仅由完整训练集构建的参考库，不读取验证/测试答案建立统计、拟合参考器或更新参数。参考视图由数据划分协议决定，不能用 model.training 代替：对训练集执行 eval 诊断仍要排除当前学生折。实现可依据已保存的训练学生折表识别学生归属，并通过显式 split context 校验。若需要在线扩大参考库，应另建实验协议。

参考器类型、允许的参考学生、超参数、实现版本与预响应预测文件应持久化；可训练参考器还保存模型哈希。参考器在轮廓形成后固定，不能随着主模型权重更新而令目标坐标漂移。首版前缀参考器无拟合参数；若替换为可训练参考器，默认在合法参考集内部做OOF预测并检验校准，防止训练拟合令残差失真，且不得引入被排除折。

### 6.3 部分证据与较充分目标

在每个允许的参考学生集合内，重复抽取学生子集，构造较少证据条件 u_partial 与较充分目标 u_dense，附带各自计数及掩码。默认可使用嵌套子集 A⊆B，记录抽样协议；不得将目标轮廓通过“条件 R”原样输入。

生成模型学习“弱证据→较充分证据”的条件分布。目标仍是有限样本估计，重采样差异不是已经校准的真实参数后验；需要下游验证其价值。

首版固定训练内部 3 折、每库 8 个条件/目标抽样视图。draw=0 使用全部合法参考学生形成 dense，并固定抽取其中 50% 学生形成 partial；其余 draw 的 dense 使用 80%—100% 合法参考学生，partial 使用其 25%—75%，均按学生无放回抽样。评估固定 full_train 库的 `eval_condition_draw=0`，不随 batch 抽取条件，也不把 dense 当 partial。边界与空集策略见实施指南。

没有观测的目标维度不作为零值监督；全部目标维度缺失的题目跳过该条去噪损失。目标可靠度可依据计数给出有界权重，按题目/参考键等权采样，避免高频事件重复支配去噪。低频题目的可恢复性依赖跨题共享，无法保证。

必须先按真实事件 ID 去重，再计算统计。长序列窗口重叠的上下文事件不能重复计数。若现有 processed 无可证明唯一的事件 ID，不得用 (学生,题目,答案) 代替，它会误删真实重复练习；应从已存在的训练事件来源构建专属 artifact 或补充事件 provenance。默认不改动现有数据清洗脚本。

## 7. 行为轮廓扩散

目标为 x0=u_dense_scaled，条件 c 包含 C_bar/S 的结构信息、D、u_partial、计数与掩码；默认不包含自由 R、完整目标 u_dense、当前/未来答案或学生 ID。参考库折号仅用于选择合法参考库，不作为预测特征。

前向过程：

```text
x_s = sqrt(alpha_bar_s)*x0 + sqrt(1-alpha_bar_s)*epsilon
x0_hat = D_theta(x_s, timestep(s), c)
```

默认仍为 x0 预测。条件宽度、轮廓宽度 H、时间嵌入宽度应分别声明，不套用旧模型固定的 `3*d+1` 输入公式。

建议使用终端信噪比足够低的日程并记录 alpha_bar_T；原 100 步 linear、beta=1e-4..0.02 的 alpha_bar_T 约 0.364，不能默认视为接近纯噪声。保留旧 linear 仅供受控兼容对照；不得悄悄改变旧模型。

采用少步 DDIM 等采样时，需实现跳步转换，而不是直接跳着使用只适合相邻 s→s-1 的 DDPM 系数。训练进入 KT 的候选与评估使用相同的反向采样器、时间网格和条件构造。去噪辅助训练仍可随机抽取单个 s，不与 KT 的实际输入路径混同。

建议 H=8、T=100、DDIM 采样步数 8，最终步直接返回 x0_hat。DDIM eta=0 仍可因不同起始噪声产生不同候选，但是否保留有效差异必须实测。没有证据时不要用强制向量分离损失制造多样性。

## 8. 两遍共享编码与责任分配

### 8.1 作答前初步预测

使用原始 Q 形成基线交互 X0_t=Q0_t+E_y(y_t)。第一遍状态 h0_t 只检索 j<t 的答案，但可使用截至 t 的无答案题目上下文。各候选预测为：

```text
l0_tm = g(h0_t, Q_tm)
p0_tm = sigmoid(l0_tm)
p0_t  = sum_m pi_qm * p0_tm
```

默认 pi_raw=0.5，其他 M 个候选各为 0.5/M。M 改变时原始 Q 的总先验不变。优先固定先验，学习先验属于后续消融。训练时预测头在同一学生、同一时间的候选维共享 dropout 掩码，避免责任来自候选之间独立的 dropout 噪声。

### 8.2 观察答案后的局部责任

```text
log_r_tm = log(pi_qm) + y_t*log(p0_tm) + (1-y_t)*log(1-p0_tm)
r_tm     = softmax_m(log_r_tm)
```

实现使用稳定的 log-sigmoid/softplus，不在概率空间直接连乘。默认使用 r.detach() 构造后续记忆；初步预测器由自身 BCE 监督。

该责任是在指定初步有限混合模型下的后验，表示这次交互对不同表征的相容程度。它不是全局题目真值后验，不会因某个学生的一次回答更新其他学生共享的题目库。两遍框架属于近似证据同化，不声称求得完整模型的精确联合后验。

默认不做硬 argmax；如加入温度或概率污染保底，必须同时说明对应的观测模型。责任温度≠1时不能继续声称未经改变的原始贝叶斯后验。先检验初步概率的校准质量。

### 8.3 历史交互证据

先在完整候选空间计算：

```text
mu_t = sum_m r_tm * Q_tm
v_t  = sum_m r_tm * (Q_tm-mu_t)^2
```

采用有基线锚点的适配器：

```text
X1_t = X0_t + A_phi([mu_t-Q0_t; v_t])
```

A_phi 首版为无偏置 Linear(2*d_q,d_q)，可零初始化。这是对讨论中任意拼接 P 的具体化：当全部候选相同，修正严格为零，便于检查方法退化行为。零初始化会让最初部分上游任务梯度为零，不应误判为图断开。

预测意外程度 y_t-p0_t 可作为独立可选输入，默认关闭；它必须有等容量 surprise-only 对照，避免把其收益误归因于候选责任。

### 8.4 共享检索器的安全路径

两遍共用同一组题目编码器、交互编码器、检索器和预测头参数。第二遍仅替换交互输入 X0→X1：

```text
question_context = QuestionEncoder(Q0, inclusive causal mask)
history_memory   = InteractionEncoder(X1, inclusive causal mask)
h1_t            = Retrieve(question_context_t,
                           keys=question_context_j,
                           values=history_memory_j, j<t)
```

Q0 始终不依赖当前答案。禁止调用 `retriever(mu, answer, valid)`：当前实现 question_encoder 的当前位置查询会读到 mu_t 中的 y_t，即便最终检索使用严格掩码仍泄漏。

当前序列在同一索引保存题目和答案，严格 j<t 已完成预测时序隔离，不要再整体右移一次历史，从而误丢最近一次响应。

### 8.5 最终预测

```text
l1_tm = g(h1_t, Q_tm)
p1_t  = sum_m pi_qm * sigmoid(l1_tm)
```

当前预测使用作答前 pi，而不是已经读取 y_t 的 r_t。当前答案仅允许影响 X1_t，进而影响 t 之后的预测。所有候选共享 h1_t，不为 M 个候选运行 M 遍 Transformer。

该方案不是递归精确滤波：责任来自原始历史第一遍状态，最终状态来自第二遍同化记忆。这一近似换取并行训练，论文必须明确。

## 9. 损失与梯度

```text
L = L_final + lambda_pilot * L_pilot + lambda_diff * L_diff
L_final = BCE(y, p1), 仅 prediction_mask
L_pilot = BCE(y, p0), 仅 prediction_mask
L_diff  = 有效目标维度上的 x0 重建误差，按参考键等权
```

建议起始 lambda_pilot=0.5、lambda_diff=0.1；它们是待验证超参数，不是已有最佳值。日志记录未加权值及系数，评估总损失仅报告最终预测 NLL，避免训练联合损失与验证 BCE 作错误比较。

不对每个候选分别用同一个答案做 BCE；否则可能推动所有候选作相同预测。Bernoulli 混合的单步 NLL 本身也只能约束平均预测，无法识别候选教育语义；固定坐标参考监督与未来预测验证都不可缺。

| 路径 | 默认梯度约定 |
| --- | --- |
| 固定参考统计、目标、抽样索引 | 无梯度 |
| r 的计算→历史适配器 | r 整体 stop-gradient |
| 候选向量→mu/v→X1→最终预测 | 保留梯度，不能连 payload 一起 detach |
| 最终混合预测→各候选 | 保留梯度 |
| 初步预测器 | 通过 L_pilot 学习；共享参数也由 L_final 更新 |
| 生成器 | 联合阶段经实际可微采样及 L_diff 更新 |
| R 独立条件 | 默认无；detach 对照只断此条件支路 |

首版不加入跨学生 InfoNCE、全状态正交、任意隐藏差值蒸馏或额外 HSIC。这些都不属于核心假设。

## 10. 训练、缓存与恢复

1. 先建立训练折、合法参考预测与固定坐标轮廓 artifact；明确所有来源和哈希。
2. 预热原始 Q 与初步 KT；候选记忆适配器保持零或关闭。
3. 用弱/较充分参考证据预训练轮廓生成器。
4. 联合训练两遍 KT、候选投影与可微反向采样；在同一 batch 内按唯一合法条件键合并生成。
5. 固定 checkpoint 后生成评估候选库并缓存，执行验证选模与最终测试。

阶段策略应显式实现，不能让普通训练入口悄悄少跑若干损失。第一版可以提供分阶段命令/配置，由统一入口恢复阶段权重；具体接入见实施指南。

训练可缓存起始噪声和静态参考输入，不能跨优化器更新缓存有计算图的完整候选：C/D/R、W_f、W_u 或去噪器更新都会使其过期。联合阶段每个 batch 重新建立计算图；缓存的离线候选只能用于明确冻结全部依赖参数的实验。

候选身份由参考库视图、题目/概念集合、候选编号、固定评估种子与模型快照决定。评估不能因 batch 大小、打乱顺序、验证后测试的调用顺序而改变候选。当前 `generator` 接口可作为随机种子来源，但仅顺序调用 generator 不足以保证按题稳定，需要按规范键派生局部噪声。

若同一道题在不同事件携带不同知识点集合，当前 NewQV2 会产生不同 S。首版保留事件语义，生成键使用 `(reference_view, problem_id, sorted_unique_skill_set)`；同题不同概念视图不强行共享同一个完整 Q。不能只按题号缓存却忽略条件差异。

## 11. 关键实验、诊断与停止条件

决定性消融：固定候选库、预测头和最终 pi 混合，仅将历史 r 换成 pi。它隔离“答案条件责任更新”的未来价值。

其他必要对照：原始 NewQV2；直接 Q/Q* 融合；候选集成但不更新历史；等容量答案门控；surprise-only；MLP/Gaussian/bootstrap 候选；M=1/2/3/4；基础 R、R 条件、注入槽和三种融合方式。

诊断至少包括：候选概率分歧、r 与 pi 距离、责任熵、raw 候选质量、候选范数、R/DeltaR/S 比例、NLL/Brier/ECE、稀疏题目分组、各阶段损失与梯度、每 epoch 时间、完整预训练成本和部署缓存成本。

保留以下失败判据：

- r 相比 pi 没有稳定未来增益：核心同化机制不成立，不能仅凭整体 AUC 宣称贡献。
- 候选预测几乎一致：责任机制近似退化，不强迫向量分离来掩盖。
- Gaussian/MLP 候选同样有效：尚未证明扩散必要性。
- surprise-only 达到相同效果：收益可能来自预测误差特征。
- 答错总被归因为“题目更难”的候选，未来追踪反而变差：出现解释消解风险。

至少覆盖 ASSIST09、ASSIST17 与一个额外数据集，多个种子并按学生估计区间；以训练交互数分桶并做受控参考稀疏化。不能仅依据类别比例解释跨数据集差异。

## 12. 验收要求

- 改 y_t 不改变 p1_t，可改变未来预测；改未来答案不影响当前预测及责任。
- 第一遍/第二遍查询与 key 无当前答案依赖，第二遍仅历史 values 含责任编码。
- 全部候选相同且关闭 surprise 时，记忆修正为零；在 eval/dropout=0 下与基线记忆路径一致。
- legacy target/both 不重复融合 R；R 关闭、条件 detach、d/2d 均按显式语义运行。
- 同一 checkpoint 与评估种子，按题候选及最终评估不因 batch 组织变化而改变，数值差仅容许常规浮点误差。
- 无验证/测试标签进入参考构造；窗口重叠不重复计数。
- checkpoint 独立恢复全部结构和参考 buffer，不依赖再次执行 prepare_training，也不受当前 YAML 改写。
- 保存/恢复、CPU/CUDA、训练与评估路径、梯度和阶段状态均有检查。

## 13. 参考研究与贡献边界

1. [UKT，AAAI 2025](https://ojs.aaai.org/index.php/AAAI/article/view/35007)：分布嵌入、Wasserstein 注意力和不确定性对比已有先例。
2. [KeenKT，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/39004)：NIG 状态、去噪重建与分布对比已有先例；DHA 聚焦题目候选与证据路由。
3. [GOOD，AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/38872)：学生状态条件的响应生成；DHA 生成题目补充轮廓并使用真实响应写入历史。
4. [LPDG，KDD 2025](https://doi.org/10.1145/3711896.3737021)：练习序列及扩散伪标签生成；DHA 不依赖合成训练集扩张作为主要机制。
5. [DisKT，WWW 2025](https://arxiv.org/abs/2503.02539)，[作者实现/正式发表信息](https://github.com/zyy-2001/DisKT)：认知偏差与能力解耦已有研究；DHA 不声称仅靠候选责任识别真实能力或消除混杂。
6. 补充近邻 [AAKT，IEEE TLT 2025](https://ieeexplore.ieee.org/document/10814095)，[作者全文](https://arxiv.org/html/2502.11817v1)：作答前/后时序已被研究；此处不对该刊作未经核验的一区声明。

上述依据用于确定机制边界，不保证名称唯一、机制首创、性能提升或可发表性。本文是需要严格实验支持的研究方案。
